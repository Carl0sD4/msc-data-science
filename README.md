# MSc Data Science

Coursework, projects and research developed during my Master's in Data Science at **Universidad Simón Bolívar** (Barranquilla, Colombia).

Content is organized by semester, then by course. Most analysis is in **R** (`.Rmd`) and **Python** (`.ipynb`), with supporting datasets, reports and slides.

## Structure

### Primer semestre

| Course | Contents |
|---|---|
| `introduccion-ciencia-datos/` | Introduction to Data Science — data cleaning and manipulation with pandas |
| `metodos-cuantitativos/` | Quantitative methods and optimization — R programming fundamentals |
| `fundamentos-estadisticos/` | Descriptive and inferential statistics |
| `analisis-metadatos-I/` | Metadata analysis and data governance — confidence intervals in R |
| `seminario-investigacion-I/` | Research seminar — notes, drafts and references |

### Segundo semestre

| Course | Contents |
|---|---|
| `gestion de datos/` | Data management |
| `MÉTODOS ESTADÍSTICOS PARA LA CIENCIA DE DATOS/` | Statistical methods for data science |
| `TÉCNICAS EMERGENTES PARA LA CIENCIA DE DATOS/` | Emerging techniques for data science |

## Tech

`R` · `Python` · `pandas` · `RMarkdown` · `Jupyter`
